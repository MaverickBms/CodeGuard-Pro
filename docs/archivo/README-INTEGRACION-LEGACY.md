# Archivo histórico — paquete de refinamiento frontend

Este documento sustituye las instrucciones de integración antiguas que se conservaron únicamente por trazabilidad.

El archivo original describía una entrega aditiva de CSS (`polish.css`) y un parche manual de `templates/base.html`. El repositorio actual ya contiene `static/css/polish.css` y otros recursos de refinamiento. Por tanto, las instrucciones originales de copiar archivos manualmente o aplicar el parche no deben ejecutarse sin revisar el estado actual.

Se conserva como antecedente histórico. No es una guía operativa vigente ni forma parte del proceso de build.

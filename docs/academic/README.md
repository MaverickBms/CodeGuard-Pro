## Política de publicación

Todo el contenido de esta carpeta es **borrador** hasta completar revisión técnica, pedagógica, de referencias y de licencias. La integración en CodeGuard Pro debe utilizar el flujo editorial existente: registrar fuentes, validar su licencia y alcance de uso, crear snapshots, enviar a revisión, aprobar y publicar. No insertar borradores directamente como contenido activo.

Los UUID curriculares deben resolverse contra la base de datos del roadmap; no se inventan identificadores. El material aquí redactado se conserva como fuente de autoría y revisión hasta completar ese mapeo.

## Revisión

Las referencias y fechas de consulta se consignan dentro de cada módulo. Deben revisarse de nuevo antes de una publicación, especialmente si describen herramientas, versiones, APIs o requisitos que puedan cambiar.

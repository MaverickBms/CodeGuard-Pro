Restaurar una copia

La restauración reemplaza la base de datos y media/ actuales. Se conserva automáticamente una copia de reversión del perfil anterior.
  1. Cierra CodeGuard Pro por completo.
  2. Abre de nuevo la aplicación y usa CodeGuard Pro → Restaurar copia de seguridad… en el menú superior.
  3. Selecciona el archivo ZIP y confirma. La aplicación se reiniciará con el perfil restaurado.

También puedes restaurar desde el entorno de desarrollo con python manage.py restaurar_backup RUTA.zip --confirm tras cerrar el servidor. No muevas ni edites el ZIP original: se conserva como fuente de recuperación.
